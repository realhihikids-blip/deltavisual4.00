# DELTA VISUALS 0.3.0 — Minecraft 1.21.11 (Fabric, Yarn)

Client-only visual mod. Nothing here gives a combat advantage: no aim/attack automation, no ESP through walls,
no reach/hitbox changes, no packet tricks.

## СТАТУС (честно)
* Код написан С НУЛЯ: в загруженном JAR не было исходников, поэтому «исправить старое» было невозможно.
* Я НЕ смог выполнить `gradlew build` (в моей среде нет сети, Gradle и jar'ов Minecraft). Проверено только:
  синтаксис `javac` без ошибок, все нераспознанные символы — это классы Minecraft/Fabric (моих собственных ошибок нет).
* Подписи Minecraft API, которые я сверил по публичной Yarn-документации 1.21.11:
  `Screen.keyPressed(KeyInput)`, `mouseClicked(Click, boolean)`, `mouseReleased(Click)`, `mouseDragged(Click, double, double)`,
  `DrawContext` (Matrix3x2fStack, `fill`, `drawText`). Остальное (HudElementRegistry, DustParticleEffect(int,float),
  `PlayerInventory.setSelectedSlot`, `ClientPlayerInteractionManager.clickSlot`, `EquippableComponent.slot()`)
  написано по памяти — это главные кандидаты на ошибки компиляции.
* Все «хрупкие» вызовы частиц/ввода вынесены в `util/Compat.java`.

## Сборка
1. Скопируйте из старого проекта `gradlew`, `gradlew.bat` и папку `gradle/` (в архиве их нет — нужен Gradle 9.x).
2. `./gradlew build` → jar в `build/libs/delta-visuals-0.3.0.jar`.
3. Пришлите мне вывод ошибок — я исправлю их по списку.
Если Gradle не находит версию, возьмите актуальные значения с https://fabricmc.net/develop/ и поправьте `gradle.properties`.

## Что реализовано
| Категория | Модули |
|---|---|
| HUD | Info (FPS/ping/XYZ/facing/clock), Armor (прочность), Item Status (готовность Pearl/Totem/Elytra) |
| Visuals | Watermark, Reach Display (только показ дистанции до цели под прицелом) |
| World | Radius Circle (декоративное кольцо из частиц, не «дальность удара») |
| Player | Pearl Swap, Totem Swap, Elytra Swap |
| Cosmetics | Aura: 9 эффектов, 2 цвета, скорость/размер/плотность/радиус/прозрачность, Preview |
| Controls | Click GUI (бинд меню, по умолчанию Right Shift), HUD Editor |
| Interface | Theme: пресеты, цвета, градиенты, прозрачность панелей, масштаб, анимации on/off, размер/жирность/цвет/тень текста |
| Configurations | Профили (next / duplicate / new / delete / save / reset all) |

* Бинды: клавиатура + любые кнопки мыши (включая боковые), «Press a key...», Esc — отмена, Delete/Backspace — очистить,
  ПКМ по кнопке — вернуть по умолчанию, предупреждение о конфликтах (с модулями и с ванильными клавишами),
  защита от эха открывающего клика, сохранение между запусками.
* Конфиг: `.minecraft/config/delta_visuals/profiles/<имя>.json`, автосохранение через ~1 с, атомарная запись,
  повреждённый файл переименовывается в `*.corrupt-<время>.json` и подставляются значения по умолчанию.
* HUD Editor: перетаскивание, колесо — масштаб, R / Shift+R — сброс, чипы внизу включают/выключают элементы.
  Позиция хранится долей экрана → не уходит за границы при смене разрешения.

## Ограничения (намеренные или технические)
* **Шрифты**: доступны размер, жирность, цвет, прозрачность, тень на ванильном шрифте. Выбор семейства шрифтов и
  сглаживание не сделаны: в 1.21.9+ изменился `Style.withFont`, а собственный рендерер шрифтов — риск совместимости.
* **Небо / окружение**: не реализовано. В 1.21.11 время суток переехало в «world clocks», а подмена неба требует
  миксинов, конфликтующих с Sodium/Iris. Безопасного варианта без сборки проверить не могу.
* **Круг дистанции и ауры** — частицы (`DustParticleEffect`). Прозрачность эмулируется вероятностью появления частиц,
  время жизни частицы определяет игра. Линия «на земле» без частиц требует собственного рендера мира.
* **Totem Swap**: с открытым инвентарём — одно ванильное действие «обмен с левой рукой»; без инвентаря только выбирает
  слот с тотемом и просит нажать вашу клавишу смены рук. Автоматики и определения опасности нет.
* **Elytra Swap**: только с открытым инвентарём, обычные клики (взять/положить/вернуть).
* **Не перенесено из старого JAR**: траектории, трансформации руки (миксин), маркеры смерти — исходников нет,
  а миксины без компиляции против 1.21.11 я писать не стал. Могу добавить следующим этапом.
* Нет сервер-специфичных проверок правил — отключайте модули, если сервер запрещает клиентские косметические моды.

Статус (честно): код написан по образцу Aura/RadiusCircle и использует только уже имеющиеся `Fx`, `Setting`, `Module`, `TextHud`
и Fabric API `AttackEntityCallback` (без миксинов). Собрать проект я не мог — ошибки компиляции присылайте списком.

**Не перенесено (требует миксинов / собственного рендера, а проверить без сборки нельзя):**
реальная 3D-лента шлейфа и 3D-цифры урона над головой (нужен свой `RenderPipeline`), шляпа (рендер сущностей),
время/небо/цвет солнца и луны, Fullbright (лайтмап). Это следующий этап — в отдельных файлах, чтобы ошибка в одном не ломала остальное.
